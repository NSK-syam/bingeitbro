# Fonts

Both fonts are bundled for the native app shell (`/app`) only and served by `next/font/local`,
so builds never fetch fonts from the network. Latin subset, variable axes.

| File | Family | Axes | License |
| --- | --- | --- | --- |
| `Archivo-Variable.woff2` | Archivo (Omnibus-Type) | wdth 62–125, wght 400–900 | SIL Open Font License 1.1 |
| `Geist-Variable.woff2` | Geist (Vercel) | wght 400–700 | SIL Open Font License 1.1 |

Source: Google Fonts (fonts.gstatic.com). The full license text with each family's copyright line
is in `OFL-Archivo.txt` and `OFL-Geist.txt` (from github.com/google/fonts).
